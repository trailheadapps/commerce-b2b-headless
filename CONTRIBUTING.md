# Contributing to Commerce B2B Headless

## This is a reference implementation — we are not accepting contributions

This repository is published as a **read-only reference** for Salesforce partners
and developers who want to understand how to build a headless B2B storefront on
the Salesforce platform.

**We are not actively maintaining this as a community project and are not
looking for or soliciting contributions.** Pull requests will not be reviewed
or merged.

If you have questions about building on the Salesforce B2B Commerce platform,
please use the official Salesforce developer resources:

- [Salesforce Developer Documentation](https://developer.salesforce.com/docs)
- [Salesforce Stack Exchange](https://salesforce.stackexchange.com)
- [Salesforce Trailhead](https://trailhead.salesforce.com)
